# Planned Features / Roadmap

This file contains feature checklists and descriptions for what MediaVore will become. Move items to `DOCS/IMPLEMENTED_FEATURES.md` when completed.

## Table of Contents

- [Movies / Series](#movies--series)
- [Books](#books)
- [Additional Ideas](#additional-ideas)

## Movies / Series

- [ ] Fetch movies by name and year.
- [ ] Add movies to the main watchlist (ordered by date added, editable in UI).
- [ ] Create named lists with custom ordering.
- [ ] Mark as watched with date seen and rating.
- [ ] Import lists through CSV.
- [ ] Show platforms where content can be watched.
- [ ] Add unpublished movies and set reminders for release dates.
- [ ] For series: track episodes and notify about new episodes.

## Books

- [ ] Record books read or to-read.
- [ ] Track finish time (if set as read).
- [ ] Rating for books.
- [ ] Handle book series numbering (0-based or custom).
- [ ] Optionally record reading time/duration.
- [ ] Add books by scanning barcodes.

## Additional Ideas

- Gamified achievements system (see `DOCS/ACHIEVEMENTS.md`).
- Import/export sync with external services.
- Multi-device sync (server-backed option).

> Tip: Keep checkboxes here until a feature is implemented then move it to `DOCS/IMPLEMENTED_FEATURES.md` with a short note about the PR/commit that implemented it.
